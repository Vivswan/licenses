# licenses

Canonical home of versioned software license texts.

Each license lives in its own directory, one directory per released
version:

- `<license>/X.Y.Z/LICENSE.md` is the binding text, written once and
  never edited; a correction arrives as a new version.
- `<license>/X.Y.Z/GUIDE.md` is its non-binding guide, clarified in
  place.
- The version a repository's `LICENSE.md` links by canonical URL is
  the text that governs that repository.

Current licenses:

- [Individual and Small Organization
  License](individual-small-organization-license/)

## Reusing these texts

Every versioned license text in this repository - current and future -
may be copied and used to license your own software: keep the
license's name and canonical URL intact and replace any Required
Notice with your own. [LICENSE.md](LICENSE.md) carries the exact
terms, for the texts and for everything else here.
